# 恒识 Evercog MVP 使用说明

> AI 政策情报与业务经验中台 — 面向中小微企业服务公司的知识治理与智能问答平台

---

## 📋 项目简介

恒识 Evercog 是一个基于 AI 的企业知识管理平台，帮助中小微企业服务公司高效管理政策情报、业务知识和员工培训。

### 核心功能

| 模块 | 说明 |
|------|------|
| 政策情报管理 | 自动采集、分析和推送政策信息 |
| 知识卡管理 | 创建、审核和共享业务知识 |
| 经验问答 | 基于知识库的智能问答系统 |
| SOP 训练 | 标准化操作流程的创建和培训 |
| Agent 工作台 | AI 辅助的任务执行和审核 |
| 企业微信集成 | 消息推送和通知 |
| 审计日志 | 关键操作全链路追溯 |
| 权限管理 | 基于角色和部门的访问控制 |

### 技术栈

- **前端**：Next.js 16 + React 19 + Tailwind CSS 4
- **后端**：Next.js API Routes
- **数据库**：Prisma ORM + SQLite（可切换 PostgreSQL）
- **AI 层**：LLM Provider 抽象（mock / deepseek / openai 可切换）
- **校验**：Zod schema validation
- **测试**：Vitest
- **认证**：JWT + HttpOnly Cookie

## 📦 安装步骤

### 1. 克隆项目

```bash
git clone <repository-url>
cd evercog-mvp
```

### 2. 安装依赖

```bash
npm install
```

### 3. 配置环境变量

```bash
# 复制环境变量模板
cp .env.example .env
```

编辑 `.env` 文件，配置必要参数：

```env
# 数据库（默认使用本地 SQLite）
DATABASE_URL="file:./dev.db"

# JWT 密钥（生产环境必须修改）
JWT_SECRET="your-secret-key-here"

# LLM 配置（可选，使用 mock 模式无需配置）
LLM_PROVIDER="mock"
```

### 4. 初始化数据库

```bash
# 推送数据库结构
npm run db:push

# 填充测试数据
npm run db:seed
```

## 📖 功能说明

### 主要页面

| 页面 | 路径 | 说明 |
|------|------|------|
| 工作台 | `/` | 首页仪表盘 |
| 政策情报 | `/policy-intelligence` | 政策链接管理 |
| 知识中台 | `/knowledge-hub` | 知识卡浏览和搜索 |
| 导师审核 | `/mentor-review` | 审核待处理事项 |
| 员工问答 | `/employee-qa` | 智能问答系统 |
| Agent 工作台 | `/agent-workspace` | AI 任务管理 |
| 企业微信集成 | `/wecom-integration` | 推送配置 |
| 系统设置 | `/settings` | 系统配置 |

### 核心业务流程

#### 1. 知识卡管理

```
创建草稿 → 提交审核 → 导师审核 → 发布/驳回 → 归档
```

#### 2. 政策情报流程

```
提交链接 → 内容采集 → 生成简报 → 审核 → 推送
```

#### 3. 经验问答流程

```
员工提问 → 知识库检索 → AI 生成回复 → 引用来源
```

#### 4. SOP 训练流程

```
导师创建任务 → 新人提交 SOP → AI 检查 → 导师审核
```

## ⚙️ 配置说明

### 环境变量

#### 数据库配置

```env
DATABASE_URL="file:./dev.db"  # SQLite 本地文件
# DATABASE_URL="postgresql://..."  # 生产环境使用 PostgreSQL
```

#### JWT 认证

```env
JWT_SECRET="your-secret-key"  # 必须修改，至少 32 位
JWT_EXPIRES_IN="24h"          # Token 有效期
```

#### LLM 配置

```env
# Mock 模式（默认，无需 API Key）
LLM_PROVIDER="mock"

# DeepSeek 模式（推荐，成本低）
LLM_PROVIDER="deepseek"
DEEPSEEK_API_KEY="your-api-key"

# OpenAI 模式
LLM_PROVIDER="openai"
OPENAI_API_KEY="your-api-key"
```

#### 企业微信推送

```env
WECOM_CORP_ID="your-corp-id"
WECOM_CORP_SECRET="your-secret"
WECOM_AGENT_ID="your-agent-id"
```

#### 安全配置

```env
# Rate Limiting
RATE_LIMIT_ANONYMOUS="60"      # 匿名用户：60 次/分钟
RATE_LIMIT_AUTHENTICATED="120" # 认证用户：120 次/分钟
RATE_LIMIT_LOGIN="10"          # 登录接口：10 次/分钟

# CORS
CORS_ORIGIN="http://localhost:3000"
CORS_CREDENTIALS="true"
```

## ❓ 常见问题

### 1. 启动失败

**问题**：`npm run dev` 后无法访问

**解决**：
```bash
# 检查端口是否被占用
netstat -ano | grep :3000

# 使用其他端口
npm run dev -- -p 3001
```

### 2. 数据库错误

**问题**：`PrismaClientKnownRequestError`

**解决**：
```bash
# 重新生成 Prisma Client
npx prisma generate

# 重置数据库
npm run db:reset
```

### 3. 依赖安装失败

**问题**：`npm install` 报错

**解决**：
```bash
# 清除缓存
rm -rf node_modules package-lock.json
npm cache clean --force

# 重新安装
npm install
```

### 4. TypeScript 类型错误

**问题**：构建时类型检查失败

**解决**：
```bash
# 清除 Next.js 缓存
rm -rf .next

# 重新构建
npm run build
```

### 5. LLM 调用失败

**问题**：AI 功能无法使用

**解决**：
```env
# 检查 .env 中的 LLM 配置
LLM_PROVIDER="mock"  # 先使用 mock 模式

# 如果使用 DeepSeek，确认 API Key 正确
DEEPSEEK_API_KEY="sk-..."
```

### 6. 登录后页面空白

**问题**：登录成功但页面不显示

**解决**：
```bash
# 清除浏览器 Cookie
# 或使用无痕模式访问

# 检查 JWT_SECRET 是否设置
grep JWT_SECRET .env
```

### 7. 测试失败

**问题**：`npm test` 报错

**解决**：
```bash
# 确保 Prisma Client 已生成
npx prisma generate

# 运行测试
npm test
```
