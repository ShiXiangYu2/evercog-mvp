## 四、安全问题

// middleware.ts:12

**问题**: 生产环境如果忘记设置 `CORS_ORIGIN`，将允许 localhost 访问。

## 五、性能问题

### PERF-01: 知识卡搜索全量加载 ⚠️

```typescript
// knowledge-card.ts
const allCards = await prisma.knowledgeCard.findMany({ ... })  // ← 无 LIMIT
```

**问题**: 当知识卡数量很大时（如 10000+），全量加载到内存再过滤+分页，内存和性能都有压力。

**建议**: 
- 短期: 添加 `take: 1000` 上限
- 长期: 使用数据库级权限过滤（将 visibilityScope 条件加入 WHERE）

---

### PERF-02: 审计日志同步写入 ⚠️

每次业务操作同步写入审计日志，增加一次 DB 写入延迟。

**建议**: 使用 `setImmediate` 或消息队列异步写入。

---

### PERF-03: LLM Provider 重复 require ⚠️

```typescript
// llm/index.ts:96
const { DeepSeekLLMProvider } = require('../providers/deepseek-provider')
```

**问题**: 每次首次调用都执行 `require`，虽然 Node.js 有模块缓存，但仍有解析开销。

**建议**: 移到文件顶部静态导入（条件性）。
