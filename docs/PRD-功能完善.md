# PRD - 功能完善

## Problem Statement

用户在使用恒识 Evercog MVP 时，发现以下功能只是占位实现，没有真实业务逻辑：
1. 导师审核按钮只弹提示，没有真实审核流程
2. SOP 沉淀为知识卡只弹提示，没有真实创建知识卡
3. 企业微信邀请接入按钮无响应
4. 系统设置筛选/导出按钮无功能

## Solution

完善以下功能的真实业务逻辑：

### 1. 导师审核功能
- 点击"审核"按钮后弹出审核弹窗
- 弹窗中可以选择"通过"或"驳回"
- 提交后调用真实 API 更新审核状态

### 2. SOP 沉淀为知识卡
- 点击"沉淀为知识卡"按钮后调用真实 API
- 创建知识卡草稿并跳转到编辑页面

### 3. 企业微信邀请接入
- 点击"邀请接入"按钮后显示邀请链接或提示

### 4. 系统设置筛选/导出
- 筛选按钮：显示筛选条件面板
- 导出按钮：调用导出 API 下载 CSV

## User Stories

1. As a 导师, I want 审核知识卡时能够选择通过或驳回, so that 我可以完成审核流程
2. As a 导师, I want 将优秀 SOP 沉淀为知识卡, so that 知识可以复用
3. As a 管理员, I want 邀请新部门接入企业微信, so that 更多人可以使用系统
4. As a 管理员, I want 筛选和导出审计日志, so that 我可以进行数据分析

## Implementation Decisions

- 模块：mentor-review, sop, wecom-integration, settings
- 接口：复用现有 API，无需新增
- 数据：复用现有数据模型
- 状态：复用现有状态机
- 权限：复用现有权限控制
- 外部依赖：无

## Testing Decisions

- 测试 seam：API 路由层
- 行为测试：按钮点击 → 弹窗显示 → 提交 → 状态更新
- 集成测试：API 调用 → 数据库更新 → 响应返回
- 手动验收：浏览器点击验证
- Eval 覆盖：四层 Eval

## Production Notes

- 上线风险：低 - 复用现有 API 和数据模型
- 数据影响：无 - 只是完善现有功能
- 权限影响：无 - 复用现有权限控制
- 监控指标：审核成功率、知识卡创建数
- 回滚方式：回滚代码即可

## Out of Scope

- 不做：新增 API 接口
- 后续版本：Agent 自动化任务、部门筛选功能
