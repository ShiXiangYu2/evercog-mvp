## 方案一：Railway 部署（推荐）

Railway 是最适合 Next.js + Prisma 项目的部署平台，支持自动构建、数据库和环境变量管理。

### 步骤 1：准备 GitHub 仓库

```bash
# 1. 在 GitHub 创建新仓库
# 2. 推送代码到 GitHub
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/your-username/evercog-mvp.git
git push -u origin main
```

### 步骤 2：注册 Railway 账号

1. 访问 https://railway.app
2. 使用 GitHub 账号登录
3. 创建新项目

### 步骤 3：连接 GitHub 仓库

1. 在 Railway 项目中点击 "New Service"
2. 选择 "GitHub Repo"
3. 选择 `evercog-mvp` 仓库
4. Railway 会自动检测 Next.js 项目并开始构建

### 步骤 4：添加 PostgreSQL 数据库

1. 在 Railway 项目中点击 "New Service"
2. 选择 "PostgreSQL"
3. 等待数据库创建完成
4. 复制数据库连接 URL

### 步骤 5：配置环境变量

在 Railway 项目的 Variables 标签页中添加：

```bash
# 数据库（Railway 会自动设置 DATABASE_URL）
# 如果需要手动设置：
DATABASE_URL="postgresql://..."

# JWT 密钥（必须修改！）
JWT_SECRET="your-strong-random-secret-here"

# LLM 配置
LLM_PROVIDER="deepseek"
DEEPSEEK_API_KEY="your-deepseek-api-key"

# 应用配置
NODE_ENV="production"
```

### 步骤 6：初始化数据库

在 Railway 项目中：

1. 点击你的应用服务
2. 进入 "Deployments" 标签
3. 点击最新部署的 "View Logs"
4. 在 Railway 控制台的 Shell 中运行：

```bash
npx prisma db push
npx prisma db seed
```

### 步骤 7：获取访问地址

1. 在 Railway 项目中点击你的应用服务
2. 进入 "Settings" 标签
3. 在 "Networking" 部分点击 "Generate Domain"
4. 获取类似 `evercog-mvp.up.railway.app` 的域名

## 方案二：Vercel 部署

Vercel 是 Next.js 的官方部署平台，但需要外部数据库。

### 步骤 1：安装 Vercel CLI

```bash
npm i -g vercel
```

### 步骤 2：登录 Vercel

```bash
vercel login
```

### 步骤 3：部署

```bash
cd evercog-mvp
vercel
```

### 步骤 4：配置环境变量

```bash
vercel env add DATABASE_URL
vercel env add JWT_SECRET
vercel env add LLM_PROVIDER
vercel env add DEEPSEEK_API_KEY
```

### 步骤 5：生产部署

```bash
vercel --prod
```

## 方案三：Docker 部署

适用于自有服务器或云服务器部署。

### 步骤 1：构建镜像

```bash
docker build -t evercog-mvp .
```

### 步骤 2：运行容器

```bash
docker run -d \
  --name evercog \
  -p 3000:3000 \
  -e DATABASE_URL="postgresql://..." \
  -e JWT_SECRET="your-secret" \
  -e LLM_PROVIDER="deepseek" \
  -e DEEPSEEK_API_KEY="your-key" \
  evercog-mvp
```

### 步骤 3：使用 Docker Compose

创建 `docker-compose.prod.yml`：

```yaml
version: '3.8'

services:
  app:
    build: .
    ports:
      - "3000:3000"
    environment:
      - DATABASE_URL=postgresql://postgres:password@db:5432/evercog
      - JWT_SECRET=your-strong-secret
      - LLM_PROVIDER=deepseek
      - DEEPSEEK_API_KEY=your-key
      - NODE_ENV=production
    depends_on:
      - db
    restart: unless-stopped

  db:
    image: postgres:16-alpine
    environment:
      - POSTGRES_USER=postgres
      - POSTGRES_PASSWORD=password
      - POSTGRES_DB=evercog
    volumes:
      - postgres_data:/var/lib/postgresql/data
    restart: unless-stopped

volumes:
  postgres_data:
```

启动：

```bash
docker-compose -f docker-compose.prod.yml up -d
```

## 环境变量配置

### 必需变量

| 变量 | 说明 | 示例 |
|------|------|------|
| `DATABASE_URL` | 数据库连接 URL | `postgresql://...` |
| `JWT_SECRET` | JWT 签名密钥（≥32位） | `e94c9b0724c2bbac...` |
| `NODE_ENV` | 运行环境 | `production` |

### 可选变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `LLM_PROVIDER` | LLM 提供商 | `mock` |
| `DEEPSEEK_API_KEY` | DeepSeek API Key | - |
| `OPENAI_API_KEY` | OpenAI API Key | - |
| `JWT_EXPIRES_IN` | Token 有效期 | `24h` |
| `CORS_ORIGIN` | CORS 允许的源 | `http://localhost:3000` |

### 生成 JWT 密钥

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

## 域名和 HTTPS

### Railway

1. 在 Railway 项目设置中添加自定义域名
2. 配置 DNS 记录指向 Railway
3. Railway 自动提供 HTTPS

### Vercel

1. 在 Vercel 项目设置中添加域名
2. 配置 DNS 记录
3. Vercel 自动提供 HTTPS

### 自有服务器

使用 Nginx 反向代理 + Let's Encrypt：

```nginx
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your-domain.com;

    ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

## 监控和告警

### Sentry 错误监控

1. 注册 Sentry 账号：https://sentry.io
2. 创建新项目，选择 Next.js
3. 安装 SDK：

```bash
npm install @sentry/nextjs
```

4. 初始化 Sentry（创建 `sentry.client.config.ts`）：

```typescript
import * as Sentry from "@sentry/nextjs";

Sentry.init({
  dsn: "your-sentry-dsn",
  tracesSampleRate: 1.0,
});
```

5. 配置环境变量：

```bash
SENTRY_DSN="your-sentry-dsn"
SENTRY_AUTH_TOKEN="your-auth-token"
```

## 备份策略

### 数据库备份

#### PostgreSQL 自动备份

```bash
# 每日备份脚本
pg_dump $DATABASE_URL > backup_$(date +%Y%m%d).sql
```

#### Railway 备份

Railway 提供自动备份功能：
1. 进入 PostgreSQL 服务设置
2. 启用 Automatic Backups
3. 配置备份保留时间

```bash
# 备份上传的文件
tar -czf backup_$(date +%Y%m%d).tar.gz uploads/
```

## 常见问题

### Q1: 部署后无法访问

检查：
1. 环境变量是否正确设置
2. 数据库连接是否正常
3. 健康检查端点是否返回正常

### Q2: 数据库连接失败

```bash
# 测试数据库连接
npx prisma db push --preview-feature
```

### Q3: AI 功能不工作

检查：
1. `LLM_PROVIDER` 是否设置为 `deepseek` 或 `openai`
2. API Key 是否正确
3. 查看应用日志中的错误信息

### Q4: 构建失败

```bash
# 本地测试构建
npm run build

# 检查 TypeScript 错误
npx tsc --noEmit
```

### Q5: 内存不足

Next.js 应用在生产环境可能需要更多内存：

```bash
# 设置 Node.js 内存限制
NODE_OPTIONS="--max-old-space-size=4096"
```

## 回滚策略

### Railway 回滚

1. 进入应用服务
2. 点击 "Deployments"
3. 找到之前的稳定版本
4. 点击 "Rollback to this version"

### Vercel 回滚

```bash
# 查看部署历史
vercel ls

# 回滚到指定版本
vercel rollback [deployment-id]
```

### Docker 回滚

```bash
# 停止当前容器
docker stop evercog

# 启动旧版本容器
docker run -d --name evercog evercog-mvp:old-version
```
