# PRD: Phase 2 功能扩展

## 1. 背景与目标

基于 Phase 1 的成功实施（安全加固完成，评分 92/100），Phase 2 聚焦于功能扩展和用户体验提升。

**目标**：完善业务闭环，提升系统实用性和用户满意度。

## 2. 用户故事

### 2.1 用户反馈系统
- **作为**员工，**我希望**对知识卡进行评分和评论，**以便**帮助改进知识质量
- **作为**管理员，**我希望**查看反馈统计，**以便**了解知识卡使用情况

### 2.2 数据导出
- **作为**管理员，**我希望**导出政策简报为 PDF，**以便**分享和存档
- **作为**运营人员，**我希望**导出知识卡为 Excel，**以便**批量编辑

### 2.3 热度分析增强
- **作为**管理员，**我希望**查看知识卡热度排名，**以便**了解热门内容
- **作为**运营人员，**我希望**查看部门使用对比，**以便**优化资源配置

### 2.4 企微推送对接
- **作为**员工，**我希望**通过企微收到政策通知，**以便**及时了解新政策
- **作为**管理员，**我希望**推送政策简报到企微群，**以便**全员知晓

## 4. 技术方案

### 4.1 用户反馈系统
- 新增 `Feedback` 模型
- 实现评分和反馈 API
- 更新知识卡排序逻辑

### 4.2 数据导出
- 使用 `pdf-lib` 生成 PDF
- 使用 `exceljs` 生成 Excel
- 使用 `csv-writer` 生成 CSV

### 4.3 热度分析增强
- 新增访问量统计字段
- 实现热度计算服务
- 更新 Dashboard 图表

### 4.4 企微推送对接
- 实现企微 API 客户端
- 更新推送服务
- 支持多种消息格式
