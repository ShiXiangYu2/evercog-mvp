# 恒识 Evercog 比赛包装材料包说明

本材料包包含三类可直接使用的比赛包装材料：

1. `evercog-competition-pitch.pptx`  
   比赛路演 PPT，共 8 页，覆盖产品定位、行业痛点、解决方案、Demo 路径、差异化与商业价值。

2. `evercog-competition-copy-and-demo.md`  
   文案与 Demo 剧本，包括一句话定位、30 秒电梯陈述、3 分钟 Demo 剧本、5 分钟 Demo 剧本、评委追问回答要点。

3. `evercog-competition-readme.md`  
   当前说明文件。

## 推荐使用方式

- 报名表/项目简介：使用 `一句话定位文案` 或 `30 秒电梯陈述`。
- 现场路演：使用 `evercog-competition-pitch.pptx`。
- 产品演示：按照 `3 分钟 Demo 剧本` 依次打开：
  1. `/`
  2. `/policy-intelligence`
  3. `/employee-qa`
  4. `/agent-workspace`
  5. `/sop`

## 核心表达

恒识 Evercog 是中小微企服公司的 AI 知识操作系统：外部政策自动跟踪，内部经验即时问答，新人能力持续训练。
